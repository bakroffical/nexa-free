# Nexa Free

Nexa is a modern SaaS and business website template built with Next.js, TypeScript, Tailwind CSS, and Lucide React.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Architecture

The template follows a modular structure:

- `app/` — application entry and global styles
- `components/layout/` — navbar and footer
- `components/sections/` — page sections
- `components/ui/` — reusable UI primitives
- `content/` — editable template content

## Customization

Most content can be changed without modifying the section components.

Edit the files inside `content/` to customize:

- Features
- Pricing
- Testimonials
- FAQ
- Statistics
- Trusted companies
- Product showcase
- How It Works

Global design tokens are defined in:

`app/globals.css`

## Demo Content

Testimonials, trusted company names, statistics, pricing, and product metrics are sample content intended for demonstration.

Replace them with your own content before production use.

The pricing interface is presentation-only and does not include billing, subscriptions, authentication, or a backend.

## Free Edition

Nexa Free provides the complete landing-page foundation and core component architecture.

The Pro edition is intended to extend this foundation with additional sections, components, interactions, and premium templates.
